# Aurora Systems Lab - public research site

This repository contains the static-site source for the Aurora Systems Lab
research website. It is built with a small Markdown-based static site generator.

## Structure

- `_config.yml` - site configuration
- `index.md` - landing page
- `_publications/` - one Markdown file per publication entry
- `CONTRIBUTING.md` - entry schema and editorial policy

## Editing publication entries

Each file in `_publications/` has YAML front matter followed by an abstract.
See `CONTRIBUTING.md` for the field definitions and the release-lead policy.
